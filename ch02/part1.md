## Q1. 리눅스 명령어가 무엇인지 설명하시오. 또, 실제 명령어의 정체는 무엇인가?
A1. 리눅스 명령어는 사용자가 리눅스 운영체제에 특정 작업을 수행하도록 지시하는 문장 형태의 입력. 실제 명령어의 정체는 실행 파일, 셸 내장 명령어, 함수 등이 있다.

## Q2. 리눅스에서 가장 많이 사용되는 명령어 10개를 조사하고 설명하시오. 또 셸에서 실행하고 결과를 첨부하시오.
A2. ls: 디렉터리 목록 확인, cd: 디렉터리 이동, pwd: 현재 경로 출력, mkdir: 디렉터리 생성, rm: 파일이나 디렉터리 삭제, cp: 파일 복사, mv: 파일 이동 및 이름 변경, cat: 파일 내용 출력, grep: 특정 문자열 검색, ps: 프로세스 상태 확인

## Q3. 셸과 커널을 구분하여 자세히 설명하시오.
A3. 커널은 하드웨어 자원을 직접 관리하는 OS의 핵심이고, 셸은 사용자의 명령을 입력받아 커널에 전달하는 번역기이다.

## Q4. 프롬프트 문자열에서 문자 ~의 의미를 조사하라.
A4. 현재 로그인한 사용자의 홈 디렉터리 경로를 뜻하는 기호이다.

## Q5. sh, bash, zsh 셸의 차이를 자세히 조사하시오.
A5. sh는 초기 유닉스의 기본 셸이고, bash는 sh를 확장한 표준 셸이며, zsh는 자동 완성과 테마 등 편의 기능을 강화한 현대적 셸이다.

## Q6. 셸 스크립트에 대하여 자세히 조사하시오.
A6. 셸 명령어를 파일에 순서대로 적어두고 자동으로 실행되게 만드는 프로그램이다.

## Q7. Windows에서 사용하는 CLI방식의 셸의 종류를 조사하라.
A7. 명령 프롬프트, PowerShell, WSL bash, Git Bash가 있다.
