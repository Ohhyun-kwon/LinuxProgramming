## 1. 용어 및 기호

| 단어/기호 | 의미 |
|---|---|
| 디렉터리 | 파일과 다른 디렉터리를 저장하고 관리하는 공간 |
| 서브 디렉터리 | 특정 디렉터리 내부에 존재하는 하위 디렉터리 |
| 작업 디렉터리 | 현재 사용자가 작업하고 있는 디렉터리 |
| 홈 디렉터리 | 사용자에게 기본적으로 할당된 개인 디렉터리 |
| `~` | 현재 사용자의 홈 디렉터리를 의미 |
| `.` | 현재 디렉터리를 의미 |
| `..` | 현재 디렉터리의 상위(부모) 디렉터리를 의미 |
| `/` | 루트 디렉터리 또는 경로에서 디렉터리를 구분하는 기호 |
| 상대경로 | 현재 작업 디렉터리를 기준으로 나타낸 경로 |
| 절대경로 | 루트 디렉터리 `/`부터 시작하여 나타낸 전체 경로 |
